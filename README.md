# f-eld.ch

Website of the **Verein F-ELD** (Förderung der elektronischen Lagedarstellung), published at <https://f-eld.ch>.
It is a [Hugo](https://gohugo.io) site that uses the same theme as [sitrep.ch](https://github.com/f-eld-ch/sitrep.ch).
The site is about the association; the software has its own site, <https://sitrep.ch>.

```sh
hugo server            # live preview on http://localhost:1313
hugo --gc --minify     # production build into public/
```

See [AGENTS.md](AGENTS.md) for how the repository is organised.
